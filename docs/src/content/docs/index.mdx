<h2 class="landing-section-title">How Arcovia works</h2>

<p class="section-subtitle">Deterministic analysis. Zero guesswork.</p>

<div class="workflow-simple">
	<div><span class="step-icon"><Icon name="folder" /></span><strong>1. Scan</strong><p>Scans your codebase and collects metadata.</p></div>
	<i>┈┈▸</i>
	<div><span class="step-icon"><Icon name="code" /></span><strong>2. Parse</strong><p>Parses AST to extract components, imports, routes, and more.</p></div>
	<i>┈┈▸</i>
	<div><span class="step-icon"><Icon name="git-graph" /></span><strong>3. Build Graph</strong><p>Builds a dependency graph to understand relationships.</p></div>
	<i>┈┈▸</i>
	<div><span class="step-icon"><Icon name="list-checks" /></span><strong>4. Evaluate</strong><p>Runs deterministic rules to detect architectural issues.</p></div>
	<i>┈┈▸</i>
	<div><span class="step-icon"><Icon name="gauge" /></span><strong>5. Score</strong><p>Calculates architecture score with clear explanations.</p></div>
	<i>┈┈▸</i>
	<div><span class="step-icon"><Icon name="file-text" /></span><strong>6. Report</strong><p>Generates a beautiful HTML report and machine-readable JSON.</p></div>

# Support

## Getting help

Start with [README.md](README.md) for installation, commands, reports, scoring, history, and benchmarking.

For bugs and feature requests, use the project's issue tracker. Include the Arcovia version, the command you ran, and a minimal reproduction or sanitized `analysis.json` when possible.

## What to avoid sharing

Never include API keys, access tokens, cookies, passwords, private repository URLs, or proprietary source files in public reports.

Security concerns belong in [SECURITY.md](SECURITY.md), not a public issue.
